# pqc — POLER Quantum Core (RQ1, RQ3, RQ4)

> Спецификация вычислительного ядра `pqc` v0.1.1: statevector-движок,
> анзац `R_y(arccos p)`, Born-сэмплирование. Ноль внешних зависимостей.

## 1. Место в архитектуре

`pqc` — второй крейт воркспейса POLER-Quantum-RS. Контейнер
[`.pqw`](pqw-format.md) (крейт `pqw`) хранит фазовое состояние; `pqc`
**оживляет** его: берёт zero-copy читатель, кодирует фазы в кубиты и
исполняет измерения по правилу Борна — полностью автономный бинарник
без Python и Qiskit.

```text
.pqw файл ──mmap──► PqwReader ──деквантование p̂──► Ansatz ──► Born sampling
                    (крейт pqw)   trit·σ/63          (крейт pqc)   отчёт/счётчики
```

## 2. Математика анзаца

Трек `p ∈ [−1, 1]` кодируется кубитом через угол `θ = arccos(p)`:

```text
|ψ⟩ = ⊗_q R_y(θ_q)|0⟩,     R_y(θ)|0⟩ = cos(θ/2)|0⟩ + sin(θ/2)|1⟩
```

Ключевое тождество (оно же — мост к McWeeny):

```text
P(b_q = 1) = sin²(θ_q/2) = (1 − cos θ_q)/2 = (1 − p_q)/2
P(b_q = 0) = (1 + p_q)/2 = λ_q   ← собственное значение McWeeny
```

Собственное значение `λ = (1+p)/2` — это в точности вероятность нуля;
очистка McWeeny `λ ← 3λ² − 2λ³` заостряет Born-распределение к
детерминированным битам. Обратная проверка кодирования:
`from_phases(p).expect_z(q) == p_q` (точность 1e-12, покрыто тестами).

Семантика тритов формата:

| трит | λ | состояние | Born-исход |
|---|---|---|---|
| `+1` | 1 | `\|0⟩` | детерминированный 0 |
| `−1` | 0 | `\|1⟩` | детерминированный 1 |
| `0` | ½ | честная монета | P(1) = 0.5 |

## 3. Два движка

| Движок | Условие | Память | Стоимость выстрела | Энтанглмент |
|---|---|---|---|---|
| `Statevector` | `d_pol ≤ max_sv_qubits` (default 20) | `2^d_pol × 16 B` | `O(d_pol)` бинарный поиск | да (гейты) |
| `PhaseAnsatz` | любое `d_pol` | `O(nnz)` | `O(nnz + d_pol/64)` | нет (продукт) |

**Выбор автоматический** (`Ansatz::from_reader`), порог настраивается
(`LoadOptions::max_sv_qubits`, CLI `--max-sv-qubits`, `--engine`).

### 3.1. Фон и спайки (LENS-семантика)

LENS отсекает дуги с `|p| < ε`. Отброшенная дуга декодируется как
`p = 0` — трит `Zero`, честная монета: это **не потеря, а фоновый режим**.
Хранимые дуги — спайки. Средний вес Хэмминга полной битовой строки:

```text
E[w] = (d_pol − nnz)/2 + Σ_arc (1 − p̂_i)/2
```

### 3.2. Popcount-трюк для фона

Вес `d` честных монет сэмплируется за `⌈d/64⌉` вызовов ГПСЧ:
`popcount` случайного `u64` распределён как `Binomial(64, ½)` —
математически то же самое, что 64 честные монеты. Для `d_pol = 65536`
это 1024 слова на выстрел вместо 65536 бросков.

## 4. Ядра SIMD без зависимостей

Владелец задал класс производительности «faer/SIMD». Крейт faer здесь
**не нужен**: его стихия — плотные GEMM, а statevector-симуляция — это
стридовые парные обновления `(i, i + 2^q)`. Поэтому:

* однокубитные ядра обходят амплитуды **блоками 2^(q+1)**: младшая и
  старшая половины блока — два непрерывных потока памяти;
* `zip` двух `&mut [Cx]` + четыре умножения-сложения на пару —
  rustc авто-векторизует это в SSE/AVX-регистры;
* параллельность — собственный fork-join на `std::thread::scope`
  (никакого rayon): потоки получают непересекающиеся подсрезы, кратные
  размеру блока, результат **побитово детерминирован** при любом числе
  потоков;
* порог распараллеливания — 2¹⁵ амплитуд (512 KiB), число потоков —
  `available_parallelism()`, максимум 8;
* `RUSTFLAGS="-C target-cpu=native"` включает AVX2/FMA на машине
  исполнения без изменения кода.

Замеры (2 vCPU, release, см. `examples/bench.rs`):

| Операция | Размер | Время |
|---|---|---|
| анзац `from_phases` (20 × R_y) | 2²⁰ амплитуд | 16 мс |
| `probabilities` (параллельно) | 2²⁰ | 2.7 мс |
| построение CDF | 2²⁰ | 7.5 мс |
| Born-сэмплирование | 100k выстрелов | 13 мс |
| последовательность гейтов (22 R_y + CNOT + H) | 2²² | 60 мс |
| product-движок | d=65536, nnz=512, 10k выстрелов | 45 мс |

## 5. Born-сэмплирование

Инверсия кумулятивного распределения: строится `cdf[i] = P(x ≤ i)`
(последний элемент принудительно 1.0 — защита от округления суммы),
выстрел — `partition_point` (бинарный поиск первого `cdf[i] > u`),
`u ~ U[0,1)` из ГПСЧ. Требование нормировки `|‖ψ‖−1| ≤ 1e-9`
проверяется явно — Born-правило определено только для чистого состояния.

### 5.1. ГПСЧ

Собственный **xoshiro256++** (Blackman–Vigna, 2019) с сеянием
SplitMix64: период 2²⁵⁶−1, `jump`/`long_jump` для непересекающихся
потоков. `next_f64` даёт 53 случайных бита мантиссы — разрешение,
достаточное для CDF любого практического размера. Крейт `rand`
не нужен.

## 6. Гейты

`R_y/R_x/R_z` (вращения), `H`, `X/Y/Z`, `CNOT`, `CZ`, произвольная
однокубитная `U2`. Конвенция индексов: бит `q` амплитуды `i` — кубит
`q`, младший бит — кубит 0 (как в qiskit) — закладка паритета для RQ4.
CNOT/CZ стреляют при control = 1; пары не покидают блок 2^(max+1),
поэтому двухкубитные ядра тоже параллелятся без атомов.

## 7. CLI

```text
pqc run <file.pqw> [--shots N] [--seed S] [--top K] [--purify N]
           [--engine auto|sv|product] [--max-sv-qubits N] [--verify] [--marginals]
pqc demo [--n N] [--shots M] [--seed S]
```

`run` открывает файл через mmap, печатает заголовок контейнера
(d_pol, nnz, ε, McWeeny-residual), выбирает движок, сэмплирует и
выводит: топ-K исходов с эмпирическими и теоретическими вероятностями,
маргиналы `P(b=1)` (теория/наблюдение), статистику веса Хэмминга.
`demo` гоняет полный конвейер в памяти (writer → bytes → reader →
ansatz → sampling) без файла.

`--purify N` применяет N шагов McWeeny к деквантованным p̂ перед
кодированием: полезно, когда квантование сетки σ/63 «размывает» слабые
спайки — заострение восстанавливает решительность распределения.

## 10. Энтанглмент-слой LENS (v0.1.2)

`Entanglement` задаёт рёбра запутывания поверх анзаца `⊗ R_y(arccos p)`:

| Режим | Рёбра | Назначение |
|---|---|---|
| `None` | — | чистый продукт (v0.1.1) |
| `Chain { Cx/Cz }` | `(q → q+1)`, `q = 0..d−2` | резонансный слой qiskit-анзаца |
| `FromTopology { Cx/Cz }` | соседние LENS-дуги `(u_k → u_{k+1})` | связывание координат внимания без плотной матрицы N×N |

**Точная семантика product-движка** — главный трюк v0.1.2. CX-слои
переставляют базисные состояния: достаточно сэмплировать независимые
биты `init_i ~ Bernoulli((1−p_i)/2)` и применить GF(2)-распространение
`bit_v ^= bit_u`:

* `Chain(Cx)` — префиксный XOR всей битовой строки; слово u64
  обрабатывается за 6 сдвиговых шагов (xor-scan), перенос между
  словами — XOR всех битов предыдущего слова: выстрел остаётся
  `O(d/64 + nnz)`;
* `FromTopology(Cx)` — префиксный XOR только на позициях дуг;
* `Cz`-слои диагональны — вероятности измерений не меняются вовсе
  (влияют только на интерференцию).

Маргиналы и вероятности паттернов дуг считаются **точно**
марковской прогонкой: `bit'_i = init_i ⊕ bit'_{i−1}` даёт рекуррентность
`P1'_i = P1'_{i−1}(1−p1_i) + (1−P1'_{i−1})·p1_i`. Совпадение с
statevector-гейтами проверено тестами до 1e-12 на всех режимах
(`entangled_product_matches_statevector`,
`from_topology_cx_matches_statevector`,
`pattern_probability_entangled_exact`).

## 11. RQ4: паритет с Qiskit (v0.1.2)

### Протокол

`pqc::parity::ParityAnsatz` — зеркало `poler_quantum.quantum.ansatz.PolerAnsatz`:
восприятие `R_y(arccos p)` → резонанс `(i → i+1)` → стабилизация `R_z`
(mode B: `gamma`; mode C: `gamma·exp(−|sin(kappa·π)|)`). Конвенция битов —
little-endian как в qiskit: бит `i` амплитуды `amps[k]` — кубит `i`.

Обмен через JSON (`pqc::json`, zero-dependency): протокол `pqc-parity/1`
несёт фазы, амплитуды re/im и Born-счётчики; раннер
`tests/qiskit_parity_runner.py` строит те же схемы в Qiskit и возвращает
вердикт. Фазы порождаются языко-агностичным контрактом
`p_k = (x_k >> 11)/2^52 − 1` (SplitMix64) — бит-в-бит в обоих языках.

### Статистическая модель (важно)

Для корректного сэмплировщика p-value отдельной конфигурации
равномерно на (0, 1): контрольный эксперимент с `numpy.multinomial`
на тех же объёмах (100k выстрелов, 18 конфигураций) даёт ~5%
конфигураций ниже 0.05 — буквальный критерий «каждая из 54
конфигураций > 0.05» ложно проваливал бы **идеальный** сэмплер.
Поэтому итоговый критерий — семейство из трёх агрегатов по режимам:

```text
Σχ²_режима ~ χ²(Σdf)   (конфигурации независимы: config_rng_seed),
p_режима > 0.05/3      (поправка Бонферрони на 3 режима A/B/C)
```

семейный уровень значимости 5% — статистически корректная форма
требования «паритет на всех базовых модах с p > 0.05». Отдельные
конфигурации проходят жёсткий пол `p > 1e-4` (ловит грубые ошибки,
терпит шум). Пулинг бинов с `E < 5` — правило Кохрена.

### Результаты (фиксированные сиды 42/1337/2026, qiskit 2.2.2)

| Метрика | Значение | Бюджет |
|---|---|---|
| max амплитуда | **1.1e-16** | < 1e-12 |
| режим A (20 конф.) | χ² = 1477.9, df = 1467, p = 0.415 | > 0.0167 |
| режим B (18 конф.) | χ² = 1570.4, df = 1467, p = 0.030 | > 0.0167 |
| режим C (18 конф.) | χ² = 1467.4, df = 1467, p = 0.492 | > 0.0167 |
| min p конфигурации | 0.030 | > 1e-4 |
| little-endian | argmax совпадает во всех 56 конф. | — |

## 12. Zero-storage стриминг (RQ3, v0.1.2)

```text
Text Chunk ──ε-density──▶ Sparse Graph ──in-memory .pqw──▶ Ansatz ──Born──▶ QCM
```

`pqw::stream::TextPhaseEncoder` (текст → фазы) + `PqwWriter::write_to_vec`
(контейнер в RAM) + `PqwReader::from_bytes` (zero-copy валидация) +
`pqc::stream::ZeroStoragePipeline` (анзац → Born → метрика). Промежуточная
запись на диск **исключена полностью** — графовый поиск `poler-engine`
получает квантовую метрику чанка за один проход памяти.

Кодирование чанка: Unicode-токены → FNV-1a64 (младшие биты — координата,
старший — полярность) → накопление → L∞-нормализация → LENS-фильтр
(ε-плотность: выживают только частотные координаты).

**Метрика когерентности** `pqc::coherence`:
`QCM = 1 − Σ_q h₂(P(b_q = 1))/d_pol ∈ [0, 1]` — степень предсказуемости
измерения относительно максимума энтропии (0 — чистый шум, 1 — полная
определённость); для произведения состояний сумма маргинальных энтропий
точна, при энтанглменте — верхняя оценка (субаддитивность). Отчёт несёт
теорию и наблюдение: зазор — калибровка сэмплирования.

**Латентность** (best-of-21, release, 2 vCPU): d=512 — **~105 мкс**
(бюджет RQ3 «< 2 мс» выполнен с запасом ×19), d=512 + topology:cx —
~147 мкс, d=4096 — ~330 мкс, d=65536 — ~1.6 мс. В debug-сборке
юнит-тест `zero_storage_latency_d512` также укладывается в 2 мс.

## 13. RQ5: петля фазового обучения Born (v0.2.0)

`pqc::learn` — замкнутый цикл непрерывного обучения фазового состояния
на чистом Rust: ни Python, ни PyTorch, ни автодифференциалл — только
правило Борна и производная сложной функции.

```text
        ┌─────────────────────────────────────────────────────┐
        │                                                     ▼
  p = cos(θ) ──Ry(arccos p)──▶ |ψ⟩ ──Born: N shots──▶ p_emp = 1 − 2·N₁/N
        ▲                                                     │
        │  p ← cos(θ − η·v)                                   │ ∇_p F(p_emp)
        │  v ← γ·v + Π_Λ[−√(1−p²)·∇_p F]   ◀──────────────────┘
        │        (McWeeny 3λ²−2λ³ каждые K шагов)
        └─────────────────────────────────────────────────────┘
```

### Математика

- **Измерение**: `p_emp,i = 1 − 2·N₁,i/N_shots` — несмещённая оценка
  параметра: `E[p_emp,i] = p_i` (шум σ ≈ 1/√N на координату);
- **Параметрический сдвиг**: `∇_θ,i F = ∇_p,i F · (−√(max(0, 1−p_i²)))` —
  цепное правило `dp/dθ = −sin θ` канонической фазы `θ = arccos(p)`;
- **Каноническая цель** `quadratic_target`: `F = ½‖p_emp − target‖²`,
  градиент `g = p_emp − target` (суррогат Борна);
- **Шаг потока** (тяжёлый шар, ср. гиперпараметры заголовка
  `dp/dt = −η·Π_Λ(∇F − γ∇ε)`): `v ← γ·v + Π_Λ[∇_θ F]`,
  `θ ← arccos(p) − η·v`, `p ← cos(θ)`;
- **Проектор причинности Π_Λ**: дуги с `|p| < ε` заморожены (LENS-фон
  не учится); в product-движке носитель дуг разрежён структурно;
- **McWeeny-пурификация** каждые `K` шагов: `p ← 2(3λ²−2λ³)−1` —
  заострение к чистым тритам, восстановление `P² = P` без переобучения.

### Движки

| Движок | Параметры | Измерение | Перекодировка |
|---|---|---|---|
| statevector | эффективные маргиналы `1−2·P(b=1)` | BornSampler по CDF | пересборка Ry-слоя |
| product | фазы дуг, фон = 0 | popcount-монеты + Бернулли | `set_arc_phases` |

Оба движка проходят DoD «сходимость за ≤ 10 шагов»: product d=512 —
потеря ↓ в 32× (η=0.25, γ=0.9, 4096 выстрелов); statevector d=6 — ↓ в 11×.
Regime-jump (инверсия цели) отслеживается за 10 шагов при умеренном
трении γ=0.5.

### Залипание на полюсах

На чистых тритах `|p| = 1` производная `dp/dθ = −sin θ` вырождается в
нуль — сдвиг фазы с полюса физически невозможен. Сильный момент
(γ ≥ 0.8) при резкой смене цели способен занести фазу точно на полюс и
залипнуть (подтверждено симуляцией: при γ=0.9 инверсия цели стопорится
на 6% за 10 шагов, при γ=0.5 — сходимость 415×). Пурификация, напротив,
целенаправленно сгоняет фазы НА полюсы — режим сходимости к тритам.

|---|---|
| d=512, product | ~2 мс |

### Замкнутый цикл с сериализацией v0.2

Обученное состояние — чистые триты — сериализуется в упакованный
контейнер `POLER_Q2` (4 дуги на байт, см. docs/pqw-format.md §11):
обучение → пурификация → `to_bytes_packed` → zero-copy перезагрузка в
контур — интеграционный тест `tests/learn_packed_v2.rs`.
